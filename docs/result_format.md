## Calculations

**1. Thermostat differential**

```
ΔT = T_in − T_out = ______ − ______ = ______ °C
```

**2. Running (duty) factor**

```
Duty factor = t_on / (t_on + t_off) = ______
```

**3. Average pull-down rate**

```
Rate = (T_initial − T_final) / time taken = ______ °C/min
```

**4. Coefficient of Performance (from the p–h chart for R-134a)**

```
Refrigerating effect      = h₁ − h₄ = ______ kJ/kg
Compressor work           = h₂ − h₁ = ______ kJ/kg
COP                       = (h₁ − h₄) / (h₂ − h₁) = ______
```

**5. Refrigerating capacity**

```
Q = ṁ (h₁ − h₄) = ______ kW  =  ______ TR      (1 TR = 3.5 kW)
```

**6. Power consumption**

```
P = V × I × cos φ = ______ W
```
